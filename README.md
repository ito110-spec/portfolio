# 【Python製 LINE Bot】

## 概要

Pythonを用いて個人開発したLINE Botです。

Python学習のアウトプットとして開発を開始し、興味を持った機能を追加しながら継続的に機能拡張を行いました。

LINE Messaging APIやGemini APIとの連携、画像処理、データベース管理、自動送信処理などを実装し、複数の外部サービスを組み合わせたアプリケーション開発を経験しました。

## 主な機能

### 占い機能

* ランダムな組み合わせによる占い結果を表示
* ユーザーごとに異なる結果を生成

### 画像共有機能

* 投稿画像を自動で保存
* 保存された画像を他ユーザーが閲覧可能
* 「いいね」機能を実装
* ユーザーごとの獲得「いいね」数を確認可能

### 毎朝自動配信機能

- GitHub Actionsを利用して毎朝自動実行
- ユーザーごとに異なる占い結果を配信
- 直近1週間に投稿された画像からランダムで1枚を配信

### 猫GIF機能

- CATAAS（Cat as a Service）からランダム猫GIFを取得
- GIFをMP4形式に変換し、LINE上で自動再生可能な形式で送信
- ffmpegを利用して動画変換・アスペクト比調整を実装

### Gemini API連携

* Gemini APIを利用したおすすめアニメ提案機能
* 入力作品数が可変でも動作するよう実装

### 流行検索機能

- Google Trends APIを利用し、検索キーワードの関連ワードや急上昇ワードを取得する機能を実装しました。
- 検索結果を分析し、関連キーワードを優先度順に表示するロジックを実装しています。

### サービス維持（Renderスリープ対策）

- Render無料プランのスリープ対策として、GitHub Actionsから定期的にエンドポイントへPingを送るワークフローを実装しました。
- 現在は検証・運用設計の一環として構成のみ保持しています。

## 工夫・試行錯誤した点

### 占い機能

* 毎日利用しても同じ結果になりにくいよう、複数項目をランダムに組み合わせる仕組みを実装しました。
* 定期的に楽しめるよう、自動配信機能も実装しました。

### 画像共有機能

* ユーザーが投稿した画像を自動でデータベースへ保存する仕組みを実装しました。
* 画像ごとに「いいね」を管理できるようデータベース設計を行い、ユーザーごとの累計獲得数も確認できるようにしました。
* CloudinaryとFirebaseの両方でデータを管理しているため、削除漏れが発生しないよう管理者専用コマンドを実装しました。
* 直近4週間に投稿された画像からランダムで1枚を毎日自動配信
* 毎日の画像配信では、全期間ではなく直近1週間に投稿された画像を対象とすることで、新しい投稿が表示されやすいようにしました。

### 毎朝自動配信機能（GitHub Actions）

* Renderの無料プランでスリープ状態になることを考慮し、定期的にエンドポイントへPingを送ることで起動状態を維持する仕組みを実装しました。
* 毎日同時刻にリクエストが集中しないよう、0〜45分のランダム待機時間を設け、アクセスが一定時刻に偏らないように設計しました。

### 猫GIF機能

* GIFがLINE公式アカウントでは自動再生されない仕様であることを確認し、動画へ変換する方式へ変更しました。
* アスペクト比の調整やGIFごとのフレーム間隔を考慮し、自然な再生速度となるよう調整しました。

### Gemini API連携

* APIの特性を確認した結果、長い会話には向かないことを理解し、1問1答形式でも活用できるおすすめアニメ機能を考案しました。
* 入力作品数が変わっても処理できるよう、可変長入力に対応しました。
